## Mac上的验证顺序

### 1. 工程与签名
- 修改唯一Bundle ID/Team；App与Widget注册同App Group
- Xcode能打开项目、识别3个targets及共享scheme
- 主App和Widget编译；Product → Test执行全部测试，无被跳过用例
- 真机安装并首次打开，不能出现App Group不可用错误

### 2. 五栏和编辑
- 分别新建无日期、今天、过去、未来及跨月跨日任务；完成后在今日/日历/搜索状态一致
- 切清单，只顺延该清单显示的过期项；另一清单不变
- 修改标题同时在Widget点完成，保存标题后仍为完成
- 新建/修改/删除清单、重复大小写标签、清单删除回收集箱
- 长笔记自动保存；输入超长标签或制造磁盘失败时仍留在编辑页；点击完成只有保存成功才退出
- 置顶、删除、重复打开、后台回来、前台跨午夜及切时区
- 纪念日：今天=0；DST前后差值；闰年2/29；未来年份开始的每年事件不提前出现

### 3. 真正的数据恢复演练
只用可丢弃测试资料执行：
1. 建立各种类型/设置/完成状态，导出到App目录外
2. 校验文件存在；先尝试截断JSON、错误版本、重复ID、未知字段导入，确认拒绝且现有数据不变
3. 修改几项后导入旧备份，确认预览数量，再显式确认覆盖
4. 验证导入前恢复副本能恢复刚才修改状态
5. 导出完整新备份，删除测试App，重新安装并从外部文件恢复，核对所有ID、状态、笔记、设置和小组件
6. 两个进程交错完成/改标题多次、恢复时打开旧Widget，确认没有丢更新或旧数据复活

### 4. 两种Widget
- 至少两种屏幕尺寸；5/6周月份、跨年、长任务、同日超过栏数
- 无数据、存储错误、首次解锁前、恢复后
- 点击不同日期、任务、加号，深链正确；连点勾选不会反复切换状态
- 月历左右箭头桌面翻月，点标题回本月；重复同目标动作幂等；旧Widget在恢复后不能写回过期月份
- 当前月、午夜；以iOS调度实际刷新为准

### 5. 分享图片
- 中英混排、emoji组合、长网址、多空行、超长标题、几十页正文
- PNG页码完整，逐页合起来包含所有文字；不能只看第一张就确认
- 取消系统分享后回到正确编辑页，重复分享不丢正文；iPad系统分享正常弹出

### 6. 图片/语音快速新建
- 飞行模式+已下载图片OCR，中文、竖拍EXIF方向、取消、重复选择、超大图
- 麦克风/语音分别允许和拒绝；设备/语言不支持离线时明确fallback
- 录音中关闭页、App进后台、来电打断、反复开始停止，麦克风确实停止
- 手动输入、多个候选、模糊日期/相对时间、跨年、编辑后保存；确认一次不会重复写入
- 快速笔记中的日期/时间与原始识别文字保存在正文

### 7. 新系统与分发
- 在实际目标iOS版本上完整回归；源码最低版本不能证明新系统已验证
- Archive/签名/Developer权限/隐私清单再检查；有真实结果后才能标记可分发


## 日期 / 提醒 / 重复新增验收

- 日期与时间段segmented、开始/结束二层选择、全天、提醒、重复；取消不写数据，确认写入，清除后取消仍保留原安排
- 全天开关后保留的隐藏时分不能在App/Widget假显示为定时任务；开始结束时间倒置要拒绝
- 每周多星期、每N周期、截止当天、月31/年2月29跳有效日期；跨DST和跨时区固定墙钟策略
- 完成重复任务只生成一个确定性下一期，两端同时完成也不生成两个；取消完成不删除已创建下一期
- 首次明确保存提醒才弹系统授权；同步接收/导入/启动/Widget不能自动弹授权
- Widget完成后，不启动主App也撤销已完成提醒并尝试排下一期；系统接受回读不是送达证明
- 通知权限拒绝、横幅/声音禁用、预算满、添加失败、重建交错；只有本App稳定前缀的通知会被移除
- 两个月后的单条提醒可立即进入有余量的队列，不设置任意30天硬窗口；超出容量明确显示待补排
- 点击通知冷启动/热启动进入正确task；编辑器打开期间不直接顶掉未保存草稿
- 后续全量两端测试还见 `IOS_MAC_LAN_SETUP.md` 与 `LAN_PROTOCOL.md`
